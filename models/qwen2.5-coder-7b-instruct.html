Qwen2.5 Coder 7B Instruct

Writes, explains and fixes code, in almost any programming language

qwenApache-2.0Included in the subscriptionReleased September 2024 · 2 years 1 month old
Install with Noodle LLM

Don't have the app? Download it here

Trained on code rather than adapted to it, which shows in the things general models get subtly wrong: it follows an existing file's conventions, explains what a function does without inventing behaviour, and is unusually good at spotting the mistake in code that looks right.

Choose it if you write software and want a second pair of eyes that stays on your machine. Not this one for general chat or writing prose — it is noticeably blunter there than Qwen3 8B, which is the same size.
