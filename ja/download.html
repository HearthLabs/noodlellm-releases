最初の 14 日間は無料。インストーラーひとつで、あとはオフラインで動きます。

Windows 10・11

64 ビット · 19 MB

NVIDIA、AMD、Intel のグラフィックスで動作し、グラフィックカードがなくても遅くはなりますが動きます。Noodle LLM は初回起動時にどれかを確認します。

Windows 版をダウンロード

初回は Windows に警告されることがあります。［詳細情報］をクリックし、［実行］を選んでください。

Apple シリコン搭載の Mac

M1 以降 · 31 MB

Mac の内蔵グラフィックスでモデルを動かします。内蔵グラフィックスは Mac のメモリを共有しています。macOS 13.3 以降が必要です。Noodle LLM は最初に開いたときに、どれだけ使えるかを確認します。

Mac 版をダウンロード

初回は Mac に止められることがあります。システム設定の「プライバシーとセキュリティ」を開き、「このまま開く」をクリックしてください。

料金

最初の 14 日間はすべて無料です。アプリ全体、カタログのすべてのオープンモデル、始めるのにカードは不要。その後は月払いまたは年払いのサブスクリプションです。

初回は Windows が警告を出します

インストーラーを実行すると、Windows が青い画面で 「Windows によって PC が保護されました」と表示します。先へ進む方法はすぐにはわかりません。まず 詳細情報をクリックし、次に 実行をクリックしてください。

これはウイルスの警告ではありません。Windows はまだ知らない新しいアプリに対してこの画面を表示します。表示されるのは最初の一回だけです。

Mac でも確認が出ます

初めて開くとき、macOS は悪質なソフトウェアかどうかを確認できないと表示します。これもウイルスの警告ではありません。「完了」をクリックし、システム設定を開いて「プライバシーとセキュリティ」に進み、下にスクロールして「このまま開く」をクリックしてください。聞かれるのは一度だけです。

必要なもの

Windows 10/11、または Apple シリコン搭載の Mac
64 ビット版 Windows、または macOS 13.3 以降の M1 以降の Mac。ほかにインストールするものはありません。Python もコマンドラインも設定も不要です。
どんなグラフィックカードでも、なくても
NVIDIA、AMD、Intel のどれでも動き、Mac では内蔵グラフィックスを使います。なければプロセッサーで動きます。遅くはなりますが使えます。
モデルを置く容量
アプリは Windows 版が 19 MB、Mac 版が 31 MB。モデルは別にダウンロードし、ひとつ 2〜10 GB ほど。どれを入れるかはあなたが決めます。
ときどきのインターネット接続
モデルのダウンロードとサブスクリプションの更新に使います。普段はネットを切っても動き、質問にネットは不要です。
